# 🌍 Global Development Indicators Dashboard - 2023

Interactive Power BI dashboard showcasing worldwide economic, environmental, health, and education insights through data cleaning, modeling, and visualization.

---

# 📌 Project Overview

This project analyzes global development data using Microsoft Power BI.  
It includes data cleaning, transformation, data modeling, DAX calculations, and interactive dashboard creation to generate meaningful comparative insights.

The dashboard helps analyze:
- Global economy (GDP, inflation, unemployment, taxation, wages)
- Environmental statistics (land use, CO₂ emissions, gasoline prices)
- Health & education indicators (mortality, life expectancy, enrollment, physicians)
- Demographic overview (population, urban vs rural distribution, life expectancy)

---

# 🛠 Tools & Skills Used

---

# 🔑 Key Insights

- Economic Analysis: Australia recorded the highest minimum wage; South Africa had the highest unemployment rate; global average inflation was 6.22%.
- Environmental Statistics: China led global CO₂ emissions; agricultural land covered 37.70% of global land use; Eritrea and Monaco had the highest gasoline prices.
- Health & Education: South Sudan and Chad had the highest maternal mortality ratios; global average life expectancy was 69.31 years; Cuba and Monaco had the highest physician density; Finland and South Korea showed strong tertiary education enrollment.
- Global Overview (2023): Global GDP reached $92.12T; total population stood at 7.64bn; US and China contributed over 64% of GDP; urbanization trends showed China and India with the largest rural populations, while the US and Japan were predominantly urban.
